Política de Privacidade

Esta página explica, de forma simples, como os dados enviados através do site da Ayusolution são utilizados.

Dados enviados pelo utilizador

Quando utiliza o formulário, pode enviar nome, telefone/WhatsApp, email opcional, serviço pretendido, tipo de pedido, urgência e uma descrição. Esses dados são usados para responder ao pedido e prestar o atendimento solicitado.

Preferências guardadas no navegador

O site pode guardar localmente preferências como idioma e tema claro/escuro. A aplicação PWA também utiliza cache técnico para melhorar o carregamento e permitir funcionamento básico offline.

Partilha de dados

A Ayusolution não utiliza os dados do formulário para publicidade de terceiros. O envio do formulário é processado pelo serviço técnico utilizado no próprio site, e o WhatsApp é usado apenas quando o utilizador escolhe contactar por essa via.

Contacto

Para dúvidas relacionadas com os dados enviados, pode contactar a Ayusolution através dos meios de contacto apresentados no site.
