AYUSOLUTION — IMAGENS

As imagens SVG desta pasta são peças ilustrativas locais criadas como fallback e galeria.
Para usar fotografias reais dos trabalhos:
1. substitua o ficheiro correspondente por uma imagem WebP/JPG optimizada;
2. mantenha o mesmo nome OU actualize o caminho no index.html;
3. use apenas fotografias próprias/autorizadas.

Os antigos links externos ainda aparecem como imagem principal em algumas secções, mas agora possuem fallback local caso deixem de funcionar.
